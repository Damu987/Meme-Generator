# Meme Generator

Meme Generator is a frontend web application built using **HTML, CSS, and JavaScript** that allows users to create memes by adding custom text to randomly selected meme images.

The project uses a separate **`data.js` file** to store meme image data. Responsiveness is handled entirely through **CSS and layout techniques**, demonstrating a clear separation between **data logic** and **UI responsiveness**.

---

## Features

*  Random meme generation using `data.js`
*  Add top and bottom text dynamically
*  Real-time meme updates using DOM manipulation
*  External JavaScript data file (`data.js`)
*  Clean and simple UI

---

## Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & responsiveness
* **JavaScript (ES6)** – Logic & DOM manipulation
* **Data Source:** Local `data.js` file
* **Version Control:** Git & GitHub
